# 📊 SalesSight: Sales & Customer Intelligence Dashboard

## 📌 Project Overview  
This project focuses on analyzing **sales performance and customer behavior** using interactive Tableau dashboards. It transforms raw transactional data into meaningful insights to support **business decision-making and performance tracking**.

## 🎯 Objectives  
- Analyze overall **sales, profit, and quantity performance**  
- Identify **top customers and high-performing products**  
- Understand **customer purchasing behavior and distribution**  
- Track **sales and profit trends over time**  

## 🛠️ Tools & Technologies  
- Tableau  
- Data Visualization  
- KPI Design  
- Data Analysis  

## 📂 Dataset  
- Dataset contains **1000+ records** of sales and customer transactions  
- Includes fields such as **sales, profit, quantity, customer details, and product categories**  

## 📈 Dashboard Features  

### 🔹 Sales Dashboard
- Displays key KPIs: **Total Sales ($733K), Total Profit ($93K), Total Quantity (12K)**  
- Tracks **year-over-year growth** (20%+ increase in key metrics)  
- Visualizes **sales and profit trends over time**  
- Highlights **profit and loss by subcategory**  

### 🔹 Customer Dashboard
- Shows **Total Customers (693) and Total Orders (1,687)**  
- Analyzes **customer distribution based on number of orders**  
- Identifies **Top 10 customers by profit contribution**  
- Tracks **sales per customer and customer-level trends**  

## 🔍 Key Insights  
- Identified **top-performing customers and high-profit contributors**  
- Observed **consistent growth trends in sales and orders**  
- Detected **loss-making subcategories** requiring attention  
- Analyzed **customer purchase patterns and segmentation**  

## 🚀 Outcome  
Developed an interactive and user-friendly dashboard that enables **real-time data exploration**, helping stakeholders make **data-driven decisions** and improve overall business performance.
